# 🤖 AI Code Review Platform

An AI-powered code review application that analyzes source code and provides useful feedback on code quality, bugs, security, performance, and possible improvements.

Built using **Python, Streamlit, and Google Gemini AI**.

---

## 🚀 Features

- 🤖 AI-powered code review
- ⭐ Code quality score
- 🐛 Bug and error detection
- 🔐 Security issue analysis
- ⚡ Performance analysis
- 💡 Code improvement suggestions
- 💻 Improved code recommendations
- 📚 Session-based review history
- 🎨 Professional dark developer-tool interface
- 🌐 Supports multiple programming languages

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Google Gemini API**
- **python-dotenv**
- **Django** – backend setup / future integration
